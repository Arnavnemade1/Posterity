# Posterity bug and UI review — October 27, 2026

This pass reviewed the shared UI, notifications, public feed, messages, search, code browser, forms, authentication redirects and existing package/database checks. Changes are local; production has not been deployed or migrated.

## Notifications

- Opening a notification now clears its unread styling and counts immediately, refreshes the shared bell after saving, and reports failed saves.
- Approved or declined items disappear from **Needs you** immediately. Undo restores the item and counts.
- The Undo timer survives client-side navigation; leaving the page no longer silently cancels an approval. Duplicate decisions are fenced and failed decisions restore the notification.
- Request text is clickable, including on phones. Approval controls wrap below the text on narrow screens.
- The control room uses the same read behavior as the notification center. Mark all read disables while saving and reports errors.
- A database trigger acknowledges owner-request notifications in the decision's transaction. Its migration also repairs existing resolved or expired request notifications, preserving other users' rows and existing read timestamps.

Apply `supabase/migrations/20261027130000_resolved_request_notifications.sql` with the application's next database deployment. The trigger and repair have been tested locally inside rollback transactions; they have not been applied to production.
